# Metabase Setup for Marketing AI Image Generation Stack

## Prerequisites
- Metabase running at http://localhost:3000
- CSV log file at `storage/metadata/run_log.csv` (generated by the n8n workflow)

## Steps

1. **First-time login**
   - Open http://localhost:3000 in your browser.
   - Follow the prompts to create an admin account (email, password).

2. **Add a new database**
   - Click on "+ New" → "Database".
   - Choose "CSV" as the database type.
   - In the "File path" field, enter: `/home/user/ComfyUI/storage/metadata/run_log.csv`
     (Note: Inside the Metabase container, the path is mapped from `./storage/metadata/run_log.csv` on the host to `/home/user/ComfyUI/storage/metadata/run_log.csv`.)
   - Click "Save".

3. **Create a simple dashboard**
   - Click "+ New" → "Dashboard".
   - Give it a name, e.g., "Marketing Image Generation Metrics".
   - Click "+ Add card".
   - Select the CSV database you just added.
   - Choose a question type:
     - "Summarize" to see counts of runs.
     - "Trend over time" to see number of runs per day.
     - "Custom" to write a simple SQL-like query (Metabase uses its own expression language).
   - Example cards:
     * **Total Runs**: Summarize table, count of rows.
     * **Approval Rate**: Custom column: `if([status] = "approved", 1, 0)` then average.
     * **Posts Success Rate**: Average of `[posted]` column.
   - Save each card to the dashboard.

4. **Schedule automatic refresh** (optional)
   - In the dashboard settings, set a refresh interval (e.g., every 15 minutes) to keep metrics up-to-date.

## Notes
- The CSV file is appended to by the n8n workflow after each run (see the "Log Run" step).
- If you change the CSV structure, you may need to resync the database in Metabase.
- For more advanced visualizations, consider using Metabase's built-in chart types (bar, line, pie, etc.).

## Troubleshooting
- If Metabase cannot read the CSV, verify file permissions: the container user must have read access to `./storage/metadata/run_log.csv`.
- Ensure the CSV has a header row and at least one data row.
- Check Metabase logs (`docker compose logs metabase`) for connection errors.
