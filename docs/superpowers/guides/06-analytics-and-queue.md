# Analytics and queue

Track published content and manage the publishing queue.

## 1. View the queue

1. Click **Queue** in the sidebar.
2. The list shows all scheduled and pending posts.
3. Columns: platform, content preview, scheduled time, status.

## 2. Edit or cancel a queued post

1. Click the post row.
2. Click **Edit** to change the time, text, or media.
3. Click **Cancel** to remove it from the queue. The post is saved as a draft.

## 3. View analytics

1. Click **Analytics** in the sidebar.
2. Choose a date range.
3. Select platforms to compare.
4. Metrics shown:
   - Impressions
   - Clicks
   - Likes
   - Comments
   - Shares
   - Follower growth

## 4. Drill into a post

1. Click a post title in the analytics table.
2. See per-platform numbers.
3. Export the data as CSV with **Download CSV**.

## 5. Compare time periods

1. In **Analytics**, enable **Compare mode**.
2. Pick a previous period.
3. The dashboard shows changes in green or red.

## 6. Account health

1. Go to **Accounts**.
2. Each card shows:
   - Token expiry
   - Scopes
   - Follower count
   - Last sync time
3. Reconnect an account before the token expires to avoid failed publishes.
