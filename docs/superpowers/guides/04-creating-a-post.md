# Creating a post

Create, preview, and publish content across multiple platforms from a single composer.

## 1. Open the composer

1. Click **Content > New post**.
2. Select the **Team** if you belong to more than one.

## 2. Choose platforms

1. In the **Platforms** section, toggle the networks you want to post to.
2. Only connected accounts for the selected platforms are shown.
3. For LinkedIn, choose **Company Page** or **Personal**.

## 3. Write content

1. Enter your main text in the composer.
2. Use the **AI assistant** button to:
   - Generate a caption
   - Improve the current text
   - Suggest hashtags
   - Translate to plain English
3. The composer warns if the text is too long for a selected platform.

## 4. Attach media

1. Click **Add media**.
2. Pick from the **Media Library** or generate a new image.
3. For multi-image posts, re-order images by drag and drop.
4. The preview updates for each platform.

## 5. Preview per platform

1. Click the **Preview** tab.
2. Switch between platform tabs to see how the post will look.
3. Edit text or media if a platform shows a warning.

## 6. Schedule or publish

### Publish now

1. Click **Publish now**.
2. The worker queues and dispatches the post. A **PublishResult** with links appears.

### Schedule

1. Click **Schedule**.
2. Pick a date and time in your team timezone.
3. The post is added to the **Queue**. The worker publishes it when the time arrives.

### Save as draft

1. Click **Save draft**.
2. The post is visible in **Content > Drafts** and can be edited later.

## 7. Track the post

1. Open **Content > Published** or **Analytics**.
2. Click the post to see per-platform metrics: impressions, clicks, likes, comments, shares.
