# Kakkava Production Ops — Visibility Era weeks 3–4 + YES Y

Companion to `social-content-core` and `content-strategy` (weeks 1–2 voice/copy
rules). This file is the *production* half: how output is batch-made, what a
piece must accomplish before publication, and why stalls happen.

Source PDFs: `OneDrive/Kakkava Sofia/{3 week,4 week,Yes maxxing}/`.

## The 5-Hour Content Method (Day 20)

The failure mode is context switching — thinking while filming, editing while
recording, rewriting hooks mid-run. Fix = strict phase separation:

| Phase | Time | Rule |
|---|---|---|
| 1. Planning & script picking | 1h | Pick/write ALL scripts before touching a camera or editor. Batch the week's topics in one sitting. |
| 2. Recording | 2h | Record everything back-to-back. No editing between takes. |
| 3. Editing | 2h | Cut, overlay text, caption — all clips in one pass. |

Never interleave phases. One week of content = one 5-hour block.

## Remove the Friction (Day 16)

Recording resistance is fear wearing a to-do list. Diagnostic reframes:

- "I don't look good on camera" → fear of judgment → post anyway
- "Background isn't right" → excuse to wait → phone + window light is enough
- "Need better lighting/equipment" → perfectionism → ship at current setup
- "I'll do it when I'm ready" → readiness never arrives → deadline decides

For agentic pipelines the equivalent: a pipeline that stalls on a missing
asset should degrade gracefully (B-roll format, text-only video) rather than
not post — see the media rule (every post carries media, never media-less).

## B-Roll + Overlay Text (Day 17)

Fast no-face format: B-roll footage + burned-in overlay text delivering the
hook/story. Use for high-volume days, b-roll-native platforms (Reels/TikTok),
and when a talking-head take isn't available. Overlay text IS the script —
hook line first, one idea, kinetic pacing (≤3s per beat).

## Stop Starting From Scratch (Day 18)

Nothing starts from zero. Existing written content is the script source:

- Caption → talking-head script
- Hook → first line of the video
- Story → narrative arc, show-don't-tell
- Comment/DM question → next post's premise

**Repurposing ≠ duplicating** — the same piece recut identically violates the
no-duplicate-posts rule. A repurpose is a new cut/format delivering a new
angle; when in doubt, draft and ask before publishing.

## Edit Fast, Post More (Day 19)

Throughput beats polish. A posted 80% video outperforms the unposted 100%
one. Editing budget: cut dead air, add overlay text, caption, done — no
color grades, transitions, or second-guessing past the phase-3 timebox.

## Hook law (Day 11) and one-thing law (bonus guide)

- "If no one stops, nothing else matters" — the first line/first second is
  the post. Hook = real situation, no answer revealed (matches the ≤12-word
  hook rule in `social-content-core`).
- One thing, fully explained — not "3 tips". Depth over lists.
- Show, don't tell — specific situation → what happened → what it means for
  the reader.

## THE YES Y™ — 4 YESes before the final YES (Yes maxxing Bonus #1)

Every sale requires four sequential YESes. Content/funnel diagnosis = find
the MISSING yes; each piece of content exists to fill exactly one:

1. **YES to YOU** — do they trust you? (relevance fast, credibility/proof,
   positioning that gives a reason to pick you) → Authority/PROBLEM posts,
   case studies.
2. **YES to the SOLUTION** — do they want this? (problem recognized, outcome
   valued, urgency understood) → pain/outcome content, audits, before-after.
3. **YES to your METHOD** — do they believe your way? (approach is clear,
   meaningfully different from generic alternatives) → how-it-works posts,
   mechanism demos (the H.O.T. "mechanism").
4. **YES to the RATE** — is it worth the price? → offer/proof/fit content,
   pricing-post CTAs.

Scoring: each leg /15 (3 statements × 1–5); the lowest leg is the bottleneck
the next content batch targets. Pre-Sold jobs map onto these: AUTHORITY→YES1,
PROBLEM→YES2, OFFER→YES4, CONFIDENCE→YES3.

## Application in this stack

- Batch generation tasks SHOULD follow the 5-Hour structure: pick all topics
  (phase 1), generate all media (phase 2), QA+publish (phase 3) — no
  generate-then-rethink loops per item.
- When choosing what to post next: run the YES Y — pick the leg furthest
  from /15 and produce for that leg, per the data-driven mandate (use
  funnel metrics to identify the weak leg).
