# Platform-specific nurture — researched cadences

## LinkedIn — multi-channel (email + touch)

| Day | Touch |
|---|---|
| 1 | Email 1 — 4 lines, one ask (survey topic → pain match) |
| 2 | LinkedIn profile view (notification, no msg) |
| 4 | LinkedIn connect, 1-line note (no pitch) |
| 7 | Value DM — "3 openers we've used for {ICP}" |
| 10 | Email 2 — case snippet / one data point |
| 14 | Breakup email — "not the right time?" |

## X/Twitter — comment-to-DM bridge (NO links in posts)

- Pinned post = lead-magnet offer; "comment 'audit' and I'll send it"
- Every commenter gets a DM with the landing-page link (delivery, not pitch)
- Then the email sequence (7 touches over ~2 weeks)
- **Never** put the link in the main post — X suppresses external links;
  the conversion mechanism lives in the DM

## Threads → Instagram

- Threads API has NO DM automation — top-of-funnel only
- Cross-post the Threads survey post to IG Story (one-tap since 2/26)
- Comment-to-DM on the pinned IG post catches the Threads audience
- Short conversational copy (100-280 chars) outperforms polished

## Instagram — comment-to-DM

- Pinned post + "comment AUDIT" → ManyChat/Graph API DM automation
- DM delivers the landing link + the resource immediately
- Native lead forms also work (keep fields to name+email only)

## Facebook — native lead ads + Messenger

- Lead Ads capture in-app (no external click) — highest completion
- Comment-to-Messenger for organic posts
- Retargeting: custom audience of engagers → educational content + email

## The shared rule

Every platform → one landing URL (cloudless.gr/survey) → EspoCRM.
The DIFFERENCE is the touch CHANNEL: LinkedIn does email+DM+connect,
X does DM, IG does comment-to-DM, FB does native-form+Messenger.
The email sequence stays the same once they're in.
